# Portofolio Streamlit — Firman Brilian

## Jalankan lokal
```bash
pip install -r requirements.txt
streamlit run app.py
```
Buka http://localhost:8501

## Edit konten
Semua data CV ada di `data.py` — edit di sana, tidak perlu sentuh `app.py`.

## Deploy gratis (Streamlit Community Cloud)
1. Push folder ini ke repo GitHub (lihat langkah git di bawah).
2. Buka https://share.streamlit.io, login dengan akun GitHub.
3. Klik "New app", pilih repo, branch `main`, dan file utama `app.py`.
4. Klik "Deploy". Tunggu 1-2 menit, website langsung live di
   `namakamu-namarepo.streamlit.app` — gratis, tanpa kartu kredit, tanpa
   konfigurasi server sama sekali.
